EXPENSES SPLITTER CALCULATOR
A simple program that splits a total expenses among multiple people .
this calculator takes the total amount and the total number of persons and calculates how much each person needs to pay.

FEATURES
⭐️ Simple and beginner-friendly python program
⭐️ Calculates equal expense distribution
⭐️ Takes user input for total amount and number of persons
⭐️ Displays the amount each person should pay

HOW IT WORKS
⭐️ Enter the total expense amount.
⭐️ Enter the number of persons sharing the expense.
⭐️ The program calculate the displays the amount per person.
